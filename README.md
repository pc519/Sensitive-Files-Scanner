# 🔍 Sensitive Files & Paths Scanner
An automated Python web auditing tool that scans websites for exposed sensitive files (.env, .git, backups, admin panels) and generates a categorized HTML risk report.

# أداة كشف الملفات والمسارات الحساسة
أداة بايثون لفحص المواقع واكتشاف الملفات الحساسة والنسخ الاحتياطية المكشوفة للعامة، مع توليد تقرير HTML يوضح درجة الخطورة لكل مسار.
